# Harbor Hustle

Jeu de gestion de port en 3D isométrique, réalisé avec Godot 4.7.

Un porte-containers vient d'accoster : à vous d'organiser le déchargement en donnant vos ordres à la souris.

## Commandes

- Molette : zoom
- Clic droit ou molette enfoncée : déplacer la vue
- ZQSD / flèches : déplacer la vue
